# 🔮 Arcanum Ecosystem

## О проекте

Arcanum Ecosystem — экосистема Telegram-ботов на базе искусственного интеллекта в сфере эзотерики, самопознания и персональных интерпретаций.

Каждый бот является самостоятельным продуктом:

* отдельный Telegram Bot
* отдельная база данных
* отдельный магазин YooKassa
* отдельные резервные копии
* отдельная аналитика

После создания линейки ботов планируется выделение общей платформы и общей административной панели.

## 💾 Резервное копирование

Каждый бот имеет:

* собственный каталог локальных бэкапов;
* собственный каталог в Google Drive;
* собственный скрипт резервного копирования.

### Примеры файлов

```text
arcanum_database_2026-06-10_03-00-00.db
matrix_database_2026-06-10_03-00-00.db
numerology_database_2026-06-10_03-00-00.db
```

### Структура Google Drive

```text
ArcanumBackups/
├── arcanum/
├── matrix/
├── numerology/
├── astrology/
├── runes/
└── dreams/
```
