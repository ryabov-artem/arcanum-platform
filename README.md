# 🔮 Арканум

Telegram-бот для AI-интерпретации раскладов Таро.

Бот работает как самостоятельный продукт в сети эзотерических Telegram-ботов.

Telegram:

```text
@tarotrus_ai_bot
```

---

## Статус проекта

| Параметр              | Значение               |
| --------------------- | ---------------------- |
| Статус                | 🟢 Production          |
| Репозиторий           | arcanum-platform       |
| Telegram Bot          | @tarotrus_ai_bot       |
| Модель                | GPT-5.4-mini           |
| Оплата                | YooKassa подключена    |
| Резервное копирование | настроено              |

## Инфраструктура

* отдельный GitHub-репозиторий;
* отдельный Telegram Bot;
* отдельная SQLite база данных;
* отдельный YooKassa ShopID;
* отдельный webhook;
* отдельный systemd-сервис;
* отдельный скрипт резервного копирования;
* локальные и облачные бэкапы.

---

## Пути на сервере

Проект:

```text
/opt/bots/tarot_bot
```

База данных:

```text
/opt/bots/tarot_bot/data/database.db
```

Локальные бэкапы:

```text
/opt/backups/arcanum
```

Google Drive:

```text
TG_Bots/Arcanum
```
